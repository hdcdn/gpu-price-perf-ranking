# 显卡性价比测算：每千元买到多少算力

9 张显卡、三个维度（卡价每千元算力 / 每千元显存 / 三年总成本每千元算力），都按 FP16 稠密最高口径、1 元/度、24 小时满载计算。

**交流群**：QQ 群 **1128010665**（加群备注：GitHub）

## 三个榜单

| 维度 | 第一名 | 最后一名 | 差距 |
|---|---|---|---|
| 卡价每千元算力 | 3080 20G（26.5 TFLOPS） | PRO 6000 96G（2.8） | 9.5× |
| 每千元显存 | 3080 20G（5.0G） | PRO 6000 96G（0.53G） | 9.4× |
| 三年总成本每千元算力 | 3080 20G（8.54） | PRO 6000 96G（2.57） | 3.3× |

## 三个反直觉发现

1. **4080S 反超 5080**：算上电费后总成本更低（卡价低 1000、功耗低 40W）
2. **PRO 6000D 84G 才是最划算的加价**：比 5090 多花 14%，多拿 162% 显存，算力还追平
3. **多卡拼显存有折扣**：4×3080（1.6万/80G/424 TFLOPS）账面碾压 1×PRO 6000D（6.6万/84G/418），但 TP 通信开销会吃掉 10–40%
